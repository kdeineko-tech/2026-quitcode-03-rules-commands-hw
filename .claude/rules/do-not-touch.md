# do-not-touch

## Контекст

`app/src/core/**` — спільне ядро агенції: той самий код працює в усіх
клієнтських воркерах. Зміни в ньому йдуть окремим PR через рев'ю платформної
команди, тому в звичайних задачах цього проєкту він не редагується — ні
«дрібний фікс», ні «додам один тип» (`materials/architecture-brief.md`,
розділ «Ядро»).

## Правило

- Не редагувати, не додавати, не видаляти файли в: `app/src/core/**`,
  `app/scripts/**`, `materials/**`, `.coderabbit.yaml`, `.github/**`.
- Без винятків «якщо задача цього потребує» — будь-яка задача це скаже. Якщо
  без зміни в `app/src/core/**` задача не виконується: **зупинись** і опиши
  текстом, що саме потрібно змінити в core і навіщо — замість того, щоб це
  зробити.

## Як перевірити

- `cd app && npm run check:rules` — рядок `core-untouched` лишається `0`
  (звіряється за хешами з `app/scripts/core.lock.json`).
- `git status --short app/src/core app/scripts materials .coderabbit.yaml .github`
  — порожній вивід.
